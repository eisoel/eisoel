# 지방국세청 정부상징 (국문 가로조합 1행)

좌측 정부상징 문양 + 우측 기관명(대한민국 정부상징체, 영문 없음)으로 구성한 7개 지방국세청 기관상징입니다.

![미리보기](logos/미리보기.png)

## 결과물

| 폴더 | 용도 | 색상 |
| --- | --- | --- |
| `logos/svg/` | 화면·웹 (벡터) | RGB — 정부청색 `#003764`, 정부적색 `#E4032E`, 정부회색 `#575757` |
| `logos/pdf/` | 인쇄·Illustrator 편집 (벡터) | 별색 `GOK_Blue`(C100 M70 Y20 K40) · `GOK_Red`(M100 Y80) — 원본 AI와 동일, 기관명 K80 |
| `logos/png/` | 문서·간편 사용 (2737×710px, 백색배경) | RGB |

* 파일명은 원본 데이터 명명 방식을 따릅니다: `서울지방국세청_국문_좌우_1행.svg` 등.
* 기관명은 아웃라인(패스)으로 변환되어 있어 서체 설치 없이 사용할 수 있습니다.
* 모든 파일의 캔버스에는 **보호공간(좌우 8r, 상하 5r)이 포함**되어 있습니다. 캔버스 안에 다른 요소를 넣지 마세요.
* `logos/구성규정_서울지방국세청.png` — 아래 규정치를 실제 결과물 위에 표시한 검증용 이미지입니다.

## 적용한 규정 (정부상징 디자인 가이드 2017 개정판)

| 항목 | 규정 | 근거 |
| --- | --- | --- |
| 정부상징 문양 | `대한민국정부_국문_좌우_1행.ai`의 벡터 값을 그대로 사용 (백색배경 0.6r 포함) | BS 1-01, 1-04 |
| 조합 형식 | 1차 소속기관 국문 가로조합, 기관명 좌측정렬 | BS 3-1-02, 3-3-01 |
| 문양 크기 | 2R (R = 10r) | BS 3-3-01 |
| 문양–기관명 간격 | 5.5r | BS 3-3-01 |
| 기관명 높이 | 10r (상하 5r), 문양 중심축 = 기관명 중심축 | BS 3-3-01 |
| 글자 수 | 7자 → 기본 크기 (3자 이하 110%, 10자 이상 85% 규정 해당 없음) | BS 3-1-03, 3-1-04 |
| 서체 | 대한민국 정부상징체 (`정부상징체.ttf`), 자간은 서체 기본값 | BS 2-01 |
| 색상 | 정부청색 · 정부적색 · 정부회색(기관명, K80) | BS 1-03 |
| 보호공간 | 좌우 8r, 상하 5r | BS 1-01 |

기관명의 글자 크기(34.656pt, 1 font unit = 0.033844pt), 기준선 위치, 시작 위치는 원본 AI의
'대한민국정부' 아웃라인을 `정부상징체.ttf` 글리프와 대조해 산출했습니다. 같은 방식으로
'대한민국정부'를 재생성하면 원본 AI와 글리프 위치 오차가 0.021pt 이하로 일치합니다.

## 사용 시 유의사항 (가이드 요약)

* 최소크기: 문양 지름 8mm(인쇄) / 20px(화면) 미만 사용 금지 — BS 1-01
* 백색배경 사용이 원칙이며, 명도대비 40% 이상의 배경 위에서는 테두리형을 쓰고 기관명을 백색으로 바꿔야 합니다
  (이 저장소의 파일은 백색배경용 기본형입니다) — BS 1-05
* 회전·변형·색상 변경·그라데이션·그림자·테두리 적용 금지 — BS 1-09 ~ 1-11

## 다시 만들기

```bash
pip install fonttools cairosvg pillow
python3 tools/build_gov_symbol.py --font path/to/정부상징체.ttf --out logos
# 다른 기관명(4~9자): python3 tools/build_gov_symbol.py --font ... 서울지방국세청
```

`정부상징체.ttf`, 원본 `.ai`, 가이드 PDF는 공개 저장소에 재배포하지 않기 위해 포함하지 않았습니다.
